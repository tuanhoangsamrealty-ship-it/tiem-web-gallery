# Phòng mẫu Tiệm Web

Trang tĩnh (HTML + ảnh WebP) trình bày các mẫu landing page theo ngành, tối ưu cho điện thoại.

- `index.html` — toàn bộ giao diện và dữ liệu mẫu
- `img/` — ảnh mẫu: `MÃ.webp` (toàn trang), `MÃ-t.webp` (thu nhỏ), `MÃ-bg.webp` (nền)

Deploy: Vercel → Add New Project → Import repo này → Framework: **Other**, không cần build command, Output directory để trống.
Link tới một mẫu cụ thể: thêm `#MÃ` vào cuối đường link, ví dụ `/#PK02`.
